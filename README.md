A one-line entry for make.fun's "Fortune Cookie Wisdom for Developers" bounty: an original fortune-cookie line for a software developer. main.ts writes the fortune to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
